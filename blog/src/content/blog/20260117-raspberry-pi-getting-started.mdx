## Install an OS
Since a Pi is totally new to me, I followed some tutorials to get started.
First of all, I needed to set up the Pi and install an OS on it. So I followed the documentation from the Raspberry Pi website: <a href="https://www.raspberrypi.com/documentation/computers/getting-started.html" target="_blank">Raspberry Pi getting started</a>.

## Raspberry Pi x Arduino
I don't just need a Pi; I also need a connection between a Pi and my Arduino.
So to try this out, I followed this tutorial: <a href="https://www.instructables.com/Connect-Your-Raspberry-Pi-and-Arduino-Uno/" target="_blank">Connect Your Raspberry Pi and Arduino Uno</a>.

## Arduino IDE on Raspberry Pi
Maybe it would be easier to just have the Arduino IDE right there on the Pi. That way, I can check the serial output and tweak things without constantly swapping my laptop in and out.

To set it up, I followed this tutorial: <a href="https://youtu.be/KwOl3wfDB24" target="_blank">Install and Run Arduino IDE on Raspberry Pi</a>.
